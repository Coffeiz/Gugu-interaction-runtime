# 年/月组内容与标题 FLIP 不同步

## 现象

完成列的年/月组展开、收起或卡片迁移时，组标题会移动，但组内内容容器可能瞬移；在大分组或底部位置尤其明显。

## 根因

Runtime 原先只捕获 `[data-layout-group]`。年/月标题和实际承载卡片、负责裁剪的 folder 容器分属不同节点，内容容器没有进入同一份 Relative FLIP 快照，因此标题和内容使用了不同的布局时序。

## 修复

分组 FLIP 同时捕获 `[data-layout-group]` 与 `[data-layout-content]`。内容 wrapper 与标题共享同一事务快照，父子位移按相对坐标计算，避免内容先跳到最终位置。

## 回归场景

- 展开/收起年组；
- 展开/收起月组，尤其是列表底部的月份；
- 卡片拖入、拖出完成列后观察年/月标题与内容是否同步移动。
